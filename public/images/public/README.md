## Notes
- Images are WebP to reduce payload size.
- The source collage contains text and visual branding baked into the pixels.
- For production UI, keep headings, buttons, and other interface text as HTML/React text rather than relying on text embedded in images.
- The crops retain their original aspect ratios; use `object-fit: cover` and set responsive aspect ratios in the UI.
- These are public-facing marketing assets only. Dashboard assets are intentionally not included yet.
