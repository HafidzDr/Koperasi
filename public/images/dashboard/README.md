# Nusantara Maju — Dashboard Visual Assets

This package contains 12 separate WebP crops from the generated dashboard illustration contact sheet.

## Member portal
- `01-dashboard-anggota-hero.webp` — member dashboard welcome/banner
- `03-anggota-profil.webp` — member profile
- `04-simpanan-ilustrasi.webp` — savings
- `05-pinjaman-ilustrasi.webp` — loans
- `06-angsuran-ilustrasi.webp` — installments
- `07-shu-ilustrasi.webp` — SHU

## Administration portal
- `02-dashboard-admin-hero.webp` — administration dashboard welcome/banner
- `08-unit-usaha-ilustrasi.webp` — business units
- `09-keanggotaan-ilustrasi.webp` — membership and verification
- `10-transaksi-ilustrasi.webp` — transaction history
- `11-laporan-analitik.webp` — reporting and analytics
- `12-pengaturan-rbac.webp` — settings and role/permission context

## Implementation notes
- Format: WebP.
- These are decorative/illustrative assets, not live UI screenshots or real cooperative data.
- Any text or interface details baked into the illustrations are decorative and should not replace actual React text, forms, tables, charts, or accessible controls.
- Use lazy loading for below-the-fold images and meaningful `alt` text when the image conveys information; use empty alt text for purely decorative images.
- The set is for member and administration dashboard surfaces only. It does not change business rules, permissions, data, or workflow behavior.
